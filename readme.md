# Morten's Custom Order Notifier

A WooCommerce plugin that notifies a Slack channel when a new order is created.

## Installation

1. Download the plugin ZIP file from [GitHub](https://github.com/nofipa/mortens-custom-woocommerce-notifier/archive/main.zip).
2. Upload and activate the plugin through the WordPress admin dashboard.

## Usage

After activation, configure the plugin settings by going to WooCommerce > Settings > Morten's Notifications. Enter your Slack channel ID and API key to enable order notifications.
